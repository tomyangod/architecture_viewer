## 三、做得对的

- Community 永不付费墙；Pro 挂在托管评论 / 本机盯梢 / 企微。
- 漂移 CI、rules、增量生成、多语言精度形成可演示闭环（demo 成片 + 落地页）。
- 指标口径与 `metrics:pull` 可每周复用；私有化报价单页降低 B 端沟通成本。

## 四、做错 / 拖慢的

- 扩展 Marketplace 与 PH 绑死（W06-01→W06-03、W09-01），扩展暂缓后整条增长链假阻塞——已解开 W09-01 对 Marketplace 的依赖。
- npm 公开发布版本落后本地（0.3.1 vs 0.11.0），安装量不等于新能力到达。
- 遥测默认关导致「激活/留存」短期不可测；接受并用 funnel.log + 人工种子反馈补洞。

## 五、Phase 3 入口条件（建议）

同时满足再开 W13 工程：

1. npm 已发布近一个月内版本；  
2. ≥1 笔 Pro 付费 **或** ≥1 份 Team/On-prem 书面意向；  
3. 连续 4 周 metrics 有可解释的安装与试用趋势。

未满足前：优先 W09-03 / W12-01 收口，而不是 OAuth 多仓。
