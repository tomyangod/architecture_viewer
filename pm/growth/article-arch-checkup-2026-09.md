## 正文

Stack Overflow 2025 开发者调查里，大约 **29%** 的人明确不信任 AI 写出来的代码。另一头，iBuidl 对约 14,000 个 PR 的实测把 **架构违规**标在 **23%** 附近——比「这段 if 写错了」更难在 diff 里看出来：Controller 直连了 DB、同名模块互相 import 成环、一层目录被 AI 整个挪走。

单测经常是绿的。架构问题要人在脑子里重建调用图。

我给自己的真实业务仓做了一次「AI 改码架构体检」。仓大约 **5.7 万行**（仓库里公开的一次摸底：246 个文件、1543 个组件、1885 个节点、3652 条关系）。工具是开源的 Architecture Viewer。**工具免费；体检收费的是人把报告读完、把误报剔除、排修复顺序、再讲 45 分钟。** 这篇文章写的是那次扫描里已经写进公开仓库的证据，不是客户案例包装。

### 3 秒看红绿，而不是再开一轮会

日常用法不是「再画一张全景架构图」，而是改完代码立刻问：这一轮结构变坏了没有？

```bash
npx --yes --package arch-viewer@0.12.2-rc.6 arch-viewer session report /绝对路径/to/repo --renderer builtin
```

对照 git HEAD（或会话快照），增量报告给出 Before / After 和红绿灯。目标体感是 **3 秒**：红了就撤销或解释，绿了再 commit。绿灯 **不等于** 业务逻辑正确，只表示这次增量没有触发你配置的结构门。

全量摸底是另一件事。对这个仓调用分层全扫时，一次实测大约 **218 条历史红灯**——那是历史债，不是今天 AI 新写出来的。所以体检交付里会故意拆成两份：**扫描报告（存量）** 和 **增量 diff（本轮）**，避免用全仓噪音冒充本周事故。

公开演示附录在仓库里：[MCP-DEMO-publicopinionmonitor.md](https://github.com/tomyangod/architecture_viewer/blob/main/docs/demos/MCP-DEMO-publicopinionmonitor.md)。隔离练习不碰真仓：把副本拷到 `/tmp`，在 `backend/routes/alerts.py` 加一行直连 `database.db_session`，再跑 `session report`。预期是一条可指认的跨层边：前台路由跳过中间层进仓库。这是人工 review 容易放、结构上却很硬的真阳性。

### 46% 误报是真的，后来修了

不要只听「我们扫出了问题」。同一条产品线上，作者自有仓（v18 / 舆情监控家族）第一周漂移检查 **24** 项里，有 **11** 项是 vendored 第三方子项目被当成自有模块，潜在误报约 **46%**（11/24）。这不是客户验证里的线上误报率，是工程验证里写进 [pm/pilots.md](https://github.com/tomyangod/architecture_viewer/blob/main/pm/pilots.md) 的第一手脏数据。

根因清楚：工具当时分不清「项目内模块」和「拷进来的爬虫子项目」。后来落地了 `.arch-viewer-ignore` / `externalDirs`。复检记录里第三方子目录从漂移清单消失、自有模块保留。**先公开误报，再公开修复**，这是我愿意把体检当服务卖的原因：人要负责声明「这 11 条不算」。

### 真阳性不只跨层，还有依赖环

增量门会报本轮**新出现**的文件级 import 环（`circular-import`，Tarjan SCC）：两文件互引是高，三文件以上是中；历史环如果本轮没碰，保持沉默。

rc.6 修过一类会把真阳性讲错的 bug：环路径若只用文件名，两个目录下的 `browser_launcher.py` 会糊成一条。现在链路用仓库相对路径；`av_explain_finding` 对环返回 `cycleEvidence`（有序环边 + 哪条新边闭合了环 + 文件/行号），修法建议点名那条新边，而不是空泛「请解除循环依赖」。

所以体检的第三件交付物是 **修复优先级**：真阳性（跨层、新环、真实漂移）→ 可挂账的历史债 → 误报。人不能把 218 条历史红灯原样交给你当 Sprint。

### 第三方分数是 7.0，不是 10

2026-09-16 的增量评估记录了同一仓上的两轮独立评估：功能 **7.0 / 10**、可用性 8.2、准确性 6.2。评语大意是「有潜力的内部工程工具，尚未到成熟通用产品」。两轮里修过的包括：解释链路在 HEAD 对照下断裂、CRLF 被当成改动、测试关联漏识别、页脚把静态校验夸成「事实核查」、环证据缺少结构。

7.0 分够用来做试点和一次付费体检，不够用来假装平台级治理。卖点停在这里比较老实。
