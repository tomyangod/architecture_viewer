## 板块一：AI 编码 Agent 市场规模与增速

**数据点 1.1｜开发者 AI 工具渗透率**
- 84% 开发者「正在使用或计划使用」AI 编码工具（2024 年为 76%）；51% 职业开发者每日使用；对 AI 输出**准确性**的信任度跌至 **29%**（前一年为 40%）。
- 来源：**Stack Overflow 2025 Developer Survey**（2025-08 发布，49,000+ 受访者）。全球。
- **限定**：29% 是对 AI 输出准确性的信任度下降，支持「对 AI 输出存在不信任」；不直接证明用户需要独立架构工具（不信任可能来自逻辑/安全/可解释性，非仅架构）。

**数据点 1.2｜平台级活跃度**
- GitHub 开发者总数 **180M+**；新开发者首周即用 Copilot 比例 **80%**；月均合并 PR **4,320 万**（同比 +23%）；全年合并 PR **5.187 亿**（+29%）；AI 相关公开仓库超 **430 万**。
- 来源：**GitHub Octoverse 2025**（2025-12）。全球。

**数据点 1.3｜企业级 AI 采纳**
- 90% 软件从业者已在工作中采用 AI；中位每日 2 小时；80%+ 称 AI 提升生产力。
- 来源：**Google DORA 2025 State of DevOps**。全球。

**数据点 1.4｜AI 生成代码占比**
- 42% 的已提交代码为 AI 生成或 AI 辅助；开发者预期 2027 年升至 **65%**。
- 来源：**Sonar 2026 State of Code Developer Survey**（1,149 名开发者）。全球。

**数据点 1.5｜市场规模（企业级）**
- 全球企业级 AI 编码 Agent 市场约 **$9.8–11.0B（年化）**。
- 来源：**Gartner Magic Quadrant for Enterprise AI Coding Agents**（2026-05）。全球。

**数据点 1.6｜中国渗透率对照**
- 中国开发者 AI 编码工具渗透率约 **30%**（美国 91%）；信通院口径约 35%。
- 来源：**IDC《中国市场代码生成产品评估, 1H25》** / **中国信通院**（2025）。中国。

## 板块二：AI 代码质量 / 审查 / 治理赛道兴起

**数据点 2.1｜CodeRabbit（赛道龙头）**
- 2025-09 完成 **$60M B 轮**（Scale Venture Partners 领投、NVIDIA 风投 NVentures 参投），投后估值 **$550M**，累计融资 $88M；ARR 超 $15M，月增约 20%，8,000+ 付费客户；创始人定位「AI 开发的治理层」。至 2026-09 约 **600 万仓库在审、17,000+ 客户、周审 200 万+ 次**（2026 规模数为单一来源，未交叉验证）。
- 来源：**TechCrunch（2025-09）** / aiwiki.ai、knowara（2026）。全球。

**数据点 2.2｜Graphite**：2025 年 **$52M B 轮**（Accel 领投），AI 审查产品 **Diamond** 嵌入 stacked-PR 工作流。来源：Sacra（2025）。全球。

**数据点 2.3｜Greptile**：约 **$30M A 轮**（Benchmark 领投，2025），全仓上下文审查，定价 $30/活跃开发者·月。来源：BirJob / Sacra（2025–2026）。全球。

**数据点 2.4｜Sonargraph MCP（竞争确认）**：hello2morrow 的 Sonargraph MCP Server，「编码 Agent 的架构良知」，提供写前架构约束检查，支持 Java/Python/C#，可独立于 Sonargraph 使用；v26.5.11 发布于 2026-09-14 左右。来源：hello2morrow 官方博客 https://blog.hello2morrow.com/2026/07/sonargraph-mcp-2/。全球。**意义**：市场有需求信号 AND 直接竞争——AV 差异化必须在真实项目中证明（更易接入、输出更可复核、噪音更低），不是「我们发明了 MCP 架构检查」。

**数据点 2.5｜「从泛审查转向架构验证」信号**：AI code review 演进至第三代「Agent Reviewers」，架构审查能力评分从第一代 5 升至第三代 78（满分 100）；行业叙事「verify architecture not code」。来源：crashbytes 三代能力模型（2026）/ SD Times《2026 Quality Collapse》（2026）。全球。

**数据点 2.6**：未找到 CodeScene 2025–2026 公开融资/增长数据。全球。

## 板块四：架构治理 / 技术债 / 架构漂移需求信号

**锚点 A｜技术债**：每年给美国造成约 **$2.41 万亿**损失，remediation 需约 $1.52 万亿；**41% 高管**将 AI 列为技术债前三大来源。来源：**Accenture 2025 Digital Core**。全球（美国）。

- 开发者约 **33%** 工作时间（约 13.5h/周）处理技术债；技术债占企业技术资产价值 20–40%。来源：Stripe《Developer Coefficient》/ McKinsey。全球。
- 75% 技术决策者预计技术债将在 2025 年升至中/高级别。来源：Forrester 2025 predictions。全球。

**锚点 B｜架构违规率（研究线索，非硬证据）**：iBuidl 对 **14,000 个 PR** 六个月观察：AI 辅助代码语法/逻辑 bug 率比人写低 12%，但**架构违规率（耦合、忽略既有抽象）高 23%**。来源：iBuidl telemetry study（经 antoniopagano.com 2026 综述引用）。全球。
- **限定**：这是**研究线索 / 博客引用**，非独立验证的市场锚点；原始报告未公开方法学/对照组细节，不可作为硬性市场证据或定价依据，仅作需求信号参考。

- 「architecture erosion at machine speed」叙事集中出现；Sonargraph 实验显示 Agent 一次会话可制造 11 类循环依赖，传统规则引擎与 PR 审查均难捕获。来源：SD Times（2026）/ hello2morrow 博客（2026）。全球。
- 未找到「架构漂移」招聘 JD 频次、社媒讨论量的公开量化数据。

## 板块五：中国市场特异性

- 中国 AI 编码渗透约 **30%**（美 91%）；「会写代码的 AI 不稀奇，能跑完整工程的 AI 才值钱」。来源：IDC 1H25 / 《财经》2025-11。中国。
- **中国市场规模存在 10 倍口径冲突**：口径甲 2025 年 **¥3.99 亿** → 2026 ¥11.73 亿（约 +187%）；口径乙 2025 年 **¥39.9 亿** → 2026 ¥117.3 亿。**未找到一致公开数据**，引用时须写区间或标注来源口径。来源：IDC（2025–2026），经多源转引。
- 国内玩家：通义灵码（Qoder）收入份额 47.6%、Trae 使用率 41.2%、CodeBuddy 约 28%/26%（不同口径）；大厂对 C 端基本免费，AI 编程是云计算获客入口，**国内几乎无独立 AI 编码创业公司**。来源：juejin.cn / 《财经》（2025-11）。
- 付费参照：CodeBuddy 企业版约 **¥19/人·月**，通义灵码专业版 **¥49/人·月**、企业版 **¥9.9 万/年**；金融/政企重数据不出境、等保三级。来源：腾讯云开发者社区等（2025）。
- **推断（非公开统计）**：中国渗透率低但增速快 + 大厂推动 + 合规刚需，使「AI 改码后的架构验收」痛点可能比海外更早显性化。

## 板块六：竞争态势小结

- **赛道温度（推断）**：2026–2027「AI 改码架构验收」仍属**早期小众利基，处于上行拐点**——融资升温 + MCP 基础设施化 + 信任缺口三重催化。
- **商品化风险（核心威胁）**：**GitHub Copilot Code Review 已随 Copilot 订阅 $0 边际成本内置**（2025 年初 GA）；CodeRabbit 等将审查打包进既有工作流——独立「找 bug 型」工具生存空间被压缩。来源：birjob.com（2026）/ GitHub（2025）。
- **差异化空白（推断）**：头部玩家聚焦 PR 行级/安全/规范审查与工作流捆绑；**「AI 改码后的增量架构对比 + 跨层违规 + 红绿灯 verdict」未被大厂与头部作为独立卖点覆盖**——是 arch-viewer 的可防守空白。

## 对商业计划的三条直接影响

1. **定价必须靠「架构级」差异化撑住**：¥4,999/年 Team 包若只做泛审查将被 Copilot（$0 内置）与 CodeRabbit（$24–30/用户·月）价格压制；价值必须锚定「增量架构对比 + 跨层违规 + verdict」。
2. **MCP 端优先分发**：MCP 已基础设施化，DevTools 是最强落地类；AV 已有 MCP Server，提交各目录是当前最精准的零成本获客。
3. **¥1,999/次诊断是切政企/金融的低价高转化探针**：三锚点共同定义需求痛点 + 中国 B 端「强定制、重合规、要发票」付费特征；一次性诊断作首单入口，再向上销售 Team 包。
