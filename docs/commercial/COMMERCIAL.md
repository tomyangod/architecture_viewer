## 能力边界（先说清楚不做什么）

- **不判断业务逻辑正确性**——不替代测试、类型检查、安全审查或人工 Code Review。
- **不做全量架构治理**——需要组织级架构看板、Git 历史热点、多仓聚合时看 Sonargraph / CodeScene。
- **不做 AI 泛审查**——不审查代码风格、性能、安全漏洞；只做可复核的结构事实：本轮改了哪些实体、有没有跨层违规、波及谁。

## 市场依据（v3 新增，2026-09-16 核验）

**为什么「AI 改码后的架构验收」值得收费——市场信号与研究线索：**

| 信号源 | 数据 | 来源 | 限定 |
|---|---|---|---|
| AI 信任度下降 | 开发者对 AI 输出**准确性**的信任度降至 **29%**（前一年 40%） | Stack Overflow 2025 开发者调查（2025-08，全球，49,000+ 样本） | 支持「对 AI 输出存在不信任」；不直接证明需要独立架构工具（不信任可能来自逻辑/安全/可解释性，非仅架构） |
| 软件质量成本 | 美国 2022 年劣质软件成本 **$2.41T**，其中技术债约 $1.52T | CISQ / Synopsys 2022 报告 | 宏观行业痛点；不作为 AV 可寻址市场使用 |
| 架构违规研究线索 | AI 辅助代码**架构违规率 +23%**（耦合上升、忽略抽象），语法/逻辑 bug 率 -12% | iBuidl 14,000-PR 六个月观察（2026，博客引用） | **研究线索**，非独立验证的市场证据；方法学/对照组未公开 |

**竞争态势补充**：Sonargraph MCP（hello2morrow）已推出架构规则检查的 MCP Server（2026-09，v26.5.11），可独立于 Sonargraph 使用，支持 Java/Python/C#——市场有需求信号**且有直接竞争**，差异化必须在真实项目中证明（更易接入、输出更可复核、噪音更低）。

**趋势判断（来源与口径详见 [market-trends-2026-09.md](market-trends-2026-09.md)）：**

1. **赛道处于上行拐点的早期利基**：AI code review 融资升温（CodeRabbit B 轮 $60M/估值 $550M、Graphite $52M、Greptile $30M），行业叙事从「验证代码」转向「验证架构」；Sonargraph MCP 的出现证明直接竞争已存在，不是「我们发明了 MCP 架构检查」。

2. **泛审查正在被商品化**：GitHub Copilot Code Review 已随 Copilot 订阅以 $0 边际成本内置——**AV 的价格只能靠「架构级增量验收」撑住**，绝不能把自己卖成「又一款 reviewer」。
3. **MCP 是当前最精准的零成本分发渠道**：MCP 已捐 Linux 基金会、SDK 月下载 5M→1.1 亿、300+ 客户端、开发者工具是最强落地类。`av_guard` MCP Server 提交各 MCP 目录是本品类最优先的获客动作。
4. **中国市场**：个人开发者工具普遍免费（通义灵码/CodeBuddy C 端免费换云入口），**愿意付费的是组织**（合规、私有化、发票）；中国 AI 编码市场存在 10 倍口径冲突（¥3.99 亿 vs ¥39.9 亿，未找到一致数据），引用时必须标注口径。

## 收费原则（v3 修订）

**分析能力永远免费；省人工、上云、进团队工作流才收费。**

v3 补充一条定价锚：**卖「组织的架构问责」，不卖「个人的审查便利」**。市场证据（0 付费 + 国内个人订阅先验困难 + 泛审查商品化）指向：付费动机最强的是「已强制推行 AI 编码、技术负责人需要为架构质量担责的团队」，而非个人开发者省一次 CI 配置。

**谁使用 vs 谁付费（三层漏斗）：**

| 层级 | 画像 | 决策条件 |
|---|---|---|
| **Free 使用者** | AI 编码者维护真实项目（含个人） | 需要可复核的结构事实 |
| **首付费方（主验证对象）** | 小团队技术负责人（5–50 人） | 跨模块评审痛点 + 有预算决策权 + 愿意试点新工具 |
| **后期扩张** | 20–200 人组织技术团队 | 首付费案例已存在 + 合规/审计需求 |

筛选标准是**问题严重性与决策权**，不以公司规模为硬门槛——一个 10 人创业公司技术负责人比 500 人大厂无预算的一线工程师更有可能成为首付费用户。

## 诊断服务交付定义（v3 新增）

**¥1,999/次架构验收诊断**，交付物：

1. 客户仓库（公开仓直接跑 / 私有仓签 NDA 后本地跑）AV 全量扫描 + 近 N 个 AI 高频变更 PR 的增量对比；
2. 一份**架构验收报告**：跨层违规清单、循环依赖、影响面热点、风险分级，每条附路径/依赖链/规则（与产品同构，可人工复核）；
3. 修复优先级建议 + 一次 45 分钟线上讲解；
4. 报告末尾带 Team 入门包转化入口（试点 4 周免费）。

**纪律（与既有验证纪律一致）**：
- 诊断收入**单独记账、不计入产品验证阶段门**（它是服务收入，不证明订阅模型成立）；
- 每次 4–6h 人工，验证期内每月接受上限 **4 单**，防止挤占试点陪跑；
- 若诊断客户无一转化为试点/Team 付费，是「产品价值不成立」的重要信号，须记入 11-06 决策输入。

## Pro 付费交付

Pro 托管检查跑**增量结构风险管线**（session diff + 影响面 + contract-rules），产出与免费侧 `pr-comment` 同构的 verdict / 风险 / 证据。对照 PR base SHA（webhook 提供）；本机文件夹检查对照 git HEAD 或 `.av/graph-baseline.json`。无法解析基线时评论会明确写「无法对照基线」，不会静默把 PR head 和自己比较。

实现：`web/lib/pro/host-drift.js`。旧图文漂移检查（`checkKit`）不再作为付费档交付。

## 获客与分销（v3 新增）

**工程冻结说明**：0.12.2-rc.6 后冻结**新功能扩张**；仍允许交付阻塞性修复（扫描失败、基线错误、明确误报、结果无法解释）并以新版本号发布，不覆盖旧包。分发是当前主要杠杆，但分发、适配度、上手流程、输出质量仍需与试点共同验证。

按优先级：

1. **MCP 目录收录（最优先，零成本）**：`av_guard` / `av_session_report` MCP Server 提交 MCP 官方 Registry、mcp.so、Glama、PulseMCP。开发者工具是 MCP 最强落地类，这是本品类当前最精准的自然流量入口。
2. **内容渠道主位**：冷 DM 已实测 0 回复（09-14 批次 9 条）；掘金/知乎文章区的软评有轻互动证据。按周产出长文（红绿样例演示、depcruise vs Import Linter vs AV 对比文、AI 改码架构破坏案例），内容是复利资产。
3. **触达按 L1–L4 阶梯执行**（见 [outreach-retro-2026-09-15.md](../../pm/growth/outreach-retro-2026-09-15.md) §4）：首次只问一句话问题 → 零承诺礼物（npx 一行命令/样例图）→ diff 演示 → 访谈与试点。绝不跳级。目标触达量 **50+ 有效触达**（按 10–20% 回复率折算 5–10 个对话）。
4. **诊断服务作为 B 端探针**：一次性 ¥1,999 比年包更易首单成交，尤其政企/金融（合规前置、要发票）。
5. **漏斗可见性**：安装后一次性引导（star/issue/反馈入口）；激活数据缺失则复盘仍只能看下载量。
