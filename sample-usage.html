🏗️ 项目架构可视化脚手架 — 集成示例

本页面演示：如何把 architecture_viewer 作为插件/组件嵌入到任意项目中。

⚡ 3 秒快速开始 推荐独立使用

  1. 把整个 architecture_viewer 文件夹复制到你的项目任意位置，例如 docs/architecture/
  2. 修改 architecture.config.js 顶部的 USER_CONFIG，填写项目名称、描述等信息
  3. 编辑同目录下的 6 个 .md 文件（C4 Context / Container / Component / Block / Class / Deployment），用你的 Mermaid 架构图替换模板
  4. 浏览器打开 architecture_visualized.html 即完成 ✅
🔗 打开脚手架（独立模式）

🔗 方式 A：URL 参数快速配置 零配置文件

直接在 HTML 链接后拼接参数，不需要修改任何文件。支持参数：tab、embed、theme、primary、title、config。

示例：指定 Tab+海洋主题 示例：嵌入模式 示例：自定义品牌色 #c2185b 
<a href="architecture_visualized.html?tab=c4-container&theme=ocean&title=MyProject">
  查看容器架构图
</a>

📦 方式 B：作为 iframe 嵌入任意页面 项目文档页集成

在你的项目 README 页面、内部 Wiki、后台管理系统的文档页中直接嵌入，支持高度自定义 + postMessage 双向通信。

💡 嵌入模式特性：
• embed=1 自动隐藏返回顶部按钮
• hideHeader=1&hideFooter=1&hideChangelog=1 只保留核心架构图
• 通过父页面 JS 发送 postMessage 可以控制切换 Tab、注入 Mermaid 代码、下载、重新渲染 
// 父页面 JS：控制嵌入的架构图 iframe
const iframe = document.querySelector('#arch-iframe');

// 切换到容器视图
iframe.contentWindow.postMessage({
  __arch_viewer__: true,
  type: 'switchTab',
  tabId: 'c4-container'
}, '*');

// 直接注入你的架构图 Mermaid 代码（不用创建 md 文件）
iframe.contentWindow.postMessage({
  __arch_viewer__: true,
  type: 'setMermaid',
  tabId: 'c4-context',
  code: `C4Context
    title 我的项目架构
    Person(userA, "用户")
    System(core, "我的系统")
    Rel(userA, core, "使用", "HTTPS")`
}, '*');

🧩 方式 C：编程式 API（全局 ARCHITECTURE_VIEWER） 高级

在同域页面或插件中直接调用公开 API，动态生成配置并创建 iframe：

// 先引入 architecture.config.js
// <script src="architecture.config.js"></script>

// 1) 获取 / 修改当前配置
console.log(ARCHITECTURE_VIEWER.getConfig());
ARCHITECTURE_VIEWER.setConfig({
  project: { title: '动态修改的标题' },
  features: { download: false, fullscreen: false }  // 按需禁用功能
});

// 2) 把配置对象编码成 URL 参数（用于 iframe src）
const urlParams = ARCHITECTURE_VIEWER.toUrlParams({
  embed: { enabled: true, hideHeader: true, defaultTab: 'class' },
  theme: { preset: 'sunset' },
  project: { title: '我的项目 - 代码结构视图' }
});
// => 'config=eyJlbWJlZCI6eyJlbmFibGVkIjp0cnVlLC...'

// 3) 快捷创建一个可嵌入的 iframe 元素
const iframe = ARCHITECTURE_VIEWER.createIframe(
  'architecture_visualized.html',  // viewer 路径
  { theme: { preset: 'forest' } }, // 配置对象
  { width: '100%', height: '700px', borderRadius: '16px' }
);
document.body.appendChild(iframe);

// 4) 给 iframe 发送命令（切换 tab / 注入代码 / 下载 ...）
ARCHITECTURE_VIEWER.postToIframe(iframe, {
  type: 'switchTab', tabId: 'deployment'
});

🎛️ 功能开关（按需裁剪功能）

在 architecture.config.js 中通过 features 字段，或 URL 参数、动态 setConfig 精细控制哪些功能启用：

features: {
  zoomPan: true,         // 缩放/平移（鼠标滚轮/拖拽）
  fullscreen: true,      // 全屏查看
  download: true,        // 导出 PNG / SVG
  search: true,          // 搜索框 + 模块匹配
  hoverHighlight: true,  // 悬停高亮关联路径
  focusMode: true,       // 点击模块聚焦（淡化无关）
  sourceRefresh: true,   // 🔄 刷新源文件按钮
  interactionTips: true  // 首次打开的操作提示气泡
}

📁 脚手架文件清单

把这些文件作为整体复制到任意项目目录即可，不依赖任何构建工具：

architecture_viewer/
├── architecture_visualized.html   # 🚀 主入口（浏览器打开这个）
├── architecture.config.js         # ⚙️  配置文件（改项目信息）+ 插件 API
│                                    #    ARCHITECTURE_VIEWER 全局对象在此暴露
├── c4-context.md                  # 🗺️ C4 Context（系统全景）模板
├── c4-container.md                # 🏠 C4 Container（容器视图）模板
├── c4-component.md                # 🔧 C4 Component（组件详情）模板
├── block-diagram.md               # 📦 分层模块图模板
├── class-diagram.md               # 💻 核心类结构模板
├── deployment-ops.md              # 🚀 部署运维图模板
├── sample-usage.html              # 📖 本页面（集成示例，可删除）
├── README.md                      # 说明文档
└── USER_GUIDE.md                  # 用户指南
💡 单文件嵌入提示： 如果你希望更轻量（比如只需要 1 张图 + 不需要 md 文件），可以直接在 config 的 tabs 中使用 inlineMermaid 或 inlineBlocks 直接写 Mermaid 代码，或者在 iframe 嵌入后用 postMessage 调用 setMermaid 动态注入。
