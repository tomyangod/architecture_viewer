Architecture Viewer
控制台 定价

不上 GitHub 也能用

本地 Pro 上手（5 步）

告诉控制台项目在哪个文件夹。图和代码对不上就红灯。试用 7 天含自动检查与企业微信；到期后仍可手动点检查。

打开控制台

1. 启动网页

cd 本项目目录
ARCH_PRO_LOCAL=1 npm run web
# 浏览器打开 http://127.0.0.1:3847/account.html

2. 注册试用 7 天

邮箱 + 至少 8 位密码 →「注册并试用 7 天」。

3. 给自己的项目出图（免费）

cd /Users/你/你的项目
npx arch-viewer init .
npx arch-viewer generate .

4. 填文件夹，点「现在检查」

路径要从 / 写起。间隔填 15 会自动再查；填 0 只手动。企业微信群机器人地址可选。

5. 红灯了怎么修

cd /Users/你/你的项目
npx arch-viewer generate .

再回控制台点一次检查。变绿即可。

试用到期

仍可手动「现在检查」和命令行 npx arch-viewer check。自动检查、企业微信推送请在控制台兑换许可证。

更细的说明（Finder 拷路径、企微怎么建机器人）见仓库 docs/commercial/PRO-LOCAL.md。
